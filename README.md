# AUTO EMPIRE

Браузерная игра про перепродажу автомобилей с обязательной регистрацией,
личным профилем, облачным прогрессом и общим чатом (Firebase).
Весь проект — один файл `index.html`, сборка не нужна.

## Как это работает для игрока

1. При открытии игры показывается экран **Вход / Регистрация** (email + пароль или Google).
   Без входа играть нельзя.
2. После регистрации по email игроку приходит письмо со ссылкой. Пока почта не подтверждена,
   показывается экран «Подтвердите почту» (кнопки «Я подтвердил» и «Отправить письмо ещё раз»;
   игра сама проверяет подтверждение каждые 5 секунд). Аккаунты Google подтверждены сразу.
   Это проверяется и в правилах Firestore, поэтому обойти экран нельзя.
3. Дальше идёт проверка подписки на Telegram-канал (как раньше), затем игра.
4. Прогресс и профиль сохраняются в облаке в `users/{uid}`: у каждого игрока свои,
   на любом устройстве. Автосохранение каждые ~90 секунд, при сворачивании вкладки и по кнопке
   «Сохранить сейчас» (Меню → Профиль → Аккаунт). Там же кнопка «Выйти».
5. Если игрок открыл игру на втором устройстве, при возврате на первое прогресс подтянется
   с более свежего (появится сообщение «Прогресс обновлён с другого устройства»).
   Играйте на одном устройстве за раз.
6. Старый прогресс, сохранённый в браузере до появления аккаунтов, один раз переносится
   в первый аккаунт, зарегистрированный на этом устройстве.
7. Ник из профиля используется в общем чате.

## Файлы

| Файл | Зачем |
|---|---|
| `index.html` | Сама игра, регистрация, облачное сохранение и чат |
| `404.html` | Страница «не найдено» для GitHub Pages |
| `.nojekyll` | Говорит GitHub Pages не обрабатывать сайт через Jekyll |
| `firestore.rules` | Правила безопасности базы (копируются в консоль Firebase) |

## Настройка Firebase (обязательно, один раз)

1. **Authentication → Sign-in method** → включи два способа:
   - **Email/Password**;
   - **Google** (укажи Project support email и сохрани).
   Способ **Anonymous** больше не нужен, можно выключить.
2. **Authentication → Settings → Authorized domains → Add domain** →
   добавь `ИМЯ.github.io` (только домен, без `https://` и без пути).
   Без этого вход выдаст `auth/unauthorized-domain`.
3. **Firestore Database** → если базы нет, нажми **Create database** (режим production).
4. **Firestore Database → Rules** → вставь **весь** файл `firestore.rules` → **Publish**.
5. **Authentication → Templates → Email address verification** (значок карандаша):
   выбери язык **Русский** и при желании поправь текст и имя отправителя. Так же можно
   настроить письмо «Сброс пароля». По умолчанию письма на английском.
6. Письма уходят с адреса Firebase и иногда попадают в «Спам». Об этом сказано на экране
   подтверждения. Если нужен свой адрес отправителя, настрой SMTP в тех же шаблонах.

Ключ `apiKey` в `index.html` публичный по замыслу Firebase. Данные защищают правила из п. 4,
а не секретность ключа.

**Важно:** аккаунты, созданные до включения подтверждения почты, тоже должны будут подтвердить
адрес (письмо можно отправить повторно с экрана подтверждения).

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub (например, `auto-empire`).
2. Загрузи в него все файлы из этой папки, включая скрытый `.nojekyll`.
   Через терминал:
   ```bash
   git init
   git add .
   git commit -m "AUTO EMPIRE"
   git branch -M main
   git remote add origin https://github.com/ИМЯ/auto-empire.git
   git push -u origin main
   ```
3. **Settings → Pages → Build and deployment**:
   Source **Deploy from a branch**, ветка **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты игра откроется на `https://ИМЯ.github.io/auto-empire/`.

Для репозитория с обычным названием впиши его имя в переменную `REPO` в `404.html`.

## Локальный запуск

Открывать `index.html` двойным кликом нельзя: Firebase Auth не работает с `file://`.
В папке проекта выполни:

```bash
python3 -m http.server 8000
```

и открой `http://localhost:8000` (домен `localhost` Firebase разрешает по умолчанию).

## Ограничения

- **Накрутка.** Прогресс считается в браузере, поэтому опытный игрок может изменить свои
  данные через консоль. Для игры с друзьями это терпимо; для честного рейтинга нужна проверка
  на сервере (Cloud Functions, платный тариф Blaze).
- **Ники не уникальны.** Двое игроков могут выбрать одинаковый ник (аккаунты при этом разные).
- **Лимиты бесплатного тарифа Firestore:** 20 000 записей и 50 000 чтений в сутки на весь проект.
  Один активный игрок делает около 40 записей в час, то есть на сотни игрок-часов в сутки хватит.
- **Вход через Google во встроенных браузерах не работает.** Если игроки открывают ссылку
  внутри Telegram, Instagram и т. п., Google запрещает там вход (это политика Google,
  обойти её на стороне игры нельзя). Игра определяет такой браузер и показывает подсказку
  «откройте в Chrome или Safari» с кнопкой «Скопировать ссылку»; вход по email работает везде.
  В обычном мобильном браузере используется всплывающее окно: если его заблокировали,
  разреши всплывающие окна для сайта.

## Если что-то не работает

- **`auth/unauthorized-domain`**: домен GitHub Pages не добавлен в Authorized domains.
- **`auth/operation-not-allowed`**: не включён Email/Password или Google в Sign-in method.
- **`Missing or insufficient permissions` в консоли (F12)**: не опубликованы правила Firestore.
- **Письмо подтверждения не приходит**: проверь «Спам», нажми «Отправить письмо ещё раз»
  (повтор доступен раз в 30 секунд). Ошибка `too-many-requests` означает слишком частые попытки.
- **`Missing or insufficient permissions` сразу после подтверждения**: обнови страницу,
  токен должен получить отметку о подтверждённой почте.
- **«Не удалось связаться с сервером входа»**: нет интернета или заблокирован `gstatic.com`.
- **Страница не обновилась после пуша**: подожди пару минут и обнови с Ctrl+F5.

## Онлайн-возможности (новое)

- **Друзья** (Меню → Друзья): личный код и ссылка `?ref=КОД`. Друг вводит код при регистрации
  (поле «Код друга») или в разделе «Друзья» в первые 7 дней. За каждого друга, дошедшего до
  2 уровня, — **50 000 ₽**; за **10 друзей** — случайная машина (500 тыс. – 4 млн ₽) в гараж.
  Награда выдаётся один раз: флаг `paid` хранится в базе, приз за 10 — в `refclaims/{uid}`.
- **Игроки** (Меню → Игроки): рейтинг живых игроков по капиталу, поиск по нику, публичный профиль
  со статистикой, аватаром, баннером и гаражом. Рейтинг ботов остался внизу страницы.
- **Доска** (нижняя вкладка): «Объявления» (продажа машин игрокам, поиск, сортировка),
  «Чат» (общий чат слит с доской: объявление автоматически публикуется в чате с кнопкой
  «Смотреть объявление»), «Мои сделки» (входящие/исходящие обмены, мои объявления).
  Комиссия 3%, цена не выше 3× оценки, до 3 активных объявлений и предложений.
- **Обмен**: профиль игрока → «Предложить обмен». Ваша машина уходит «в залог» до ответа,
  при отказе или отмене возвращается. Если в гараже нет места, машина ждёт, пока оно освободится.
- **Оформление гаража** (вкладка Гараж → «Оформить»): стены, пол, подсветка, декор, вывеска
  с вашим текстом. За игровые деньги. Видно другим игрокам в вашем профиле.

### Что обновить в Firebase
1. **Firestore → Rules**: вставьте весь новый `firestore.rules` → Publish (обязательно,
   иначе новые разделы выдадут `Missing or insufficient permissions`).
2. Новых включений в Authentication не нужно.
3. Если в консоли браузера (F12) появится ошибка `failed-precondition` со ссылкой на создание
   индекса для `listings` — откройте ссылку и нажмите «Create». Без индекса доска работает
   в упрощённом режиме (последние 120 объявлений).

### Ограничения онлайн-части
- Деньги и прогресс считаются в браузере, как и раньше: взломщик может подделать рейтинг или
  цену. Правила защищают от чужих записей, двойной покупки и повторной награды, но не от
  модифицированного клиента. Для честной экономики нужны Cloud Functions (тариф Blaze).
- Публичный профиль обновляется не чаще раза в ~3 минуты и при выходе. Нагрузка на бесплатный
  тариф: примерно 60 записей в час на активного игрока.
- Рейтинг и поиск видят только игроки, уже заходившие после этого обновления.
